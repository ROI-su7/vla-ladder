## 一份课程，三种打开方式

本项目的每一课都是一个 Markdown 源文件（在 `lessons/` 目录下），它会被自动构建成三种形式：

| 方式 | 适合做什么 | 怎么打开 |
|---|---|---|
| 📖 **在线网站** | 系统地阅读原理、看公式和代码 | `https://roi-su7.github.io/vla-ladder/` |
| 🧪 **Colab 练习本** | 不装任何环境，在浏览器里直接写代码、跑代码 | 点每课标题下方的 ![Colab](https://colab.research.google.com/assets/colab-badge.svg) 徽章 |
| 💻 **本地 Jupyter** | 有 GPU、想长期折腾 | `git clone` 后 `pip install -e .`，用 Jupyter 打开 `notebooks/` |

> 在 GitHub 上直接点开 `lessons/` 里的 `.md` 文件也能完整阅读（公式、折叠答案都能显示）。

## 每一课的结构

每课都按同一个套路组织，养成固定的学习节奏：

1. **为什么要学**：这个知识点在 VLA / 机器人里用在哪。
2. **原理**：从直觉讲到公式，公式里每个符号都会解释。
3. **代码**：先看一个完整的小例子，逐行注释。
4. **练习**：一个填空函数（带 `TODO`）。
   - 下面紧跟一个折叠起来的 **💡 参考答案**：
     - 在网站 / GitHub 上：点一下就展开。
     - 在 Colab 上：答案单元的代码默认隐藏，点击单元左侧的"显示代码"（或双击单元）即可查看。
     - 在 JupyterLab 上：答案单元默认折叠，点左侧的蓝色竖条展开。
   - 再下面是 **✅ 自测** 单元：运行它，看到"通过"就说明你写对了。
5. **小结与思考题**。

### 关于"参考答案单元"的一个重要约定

**运行答案单元会用参考实现覆盖你写的同名函数。** 后面的代码往往依赖前面练习的函数，如果你实在写不出来，就展开答案、读懂、运行它，然后继续往下走，不要卡死在一个地方。但请务必遵守下面的"三遍法"：

1. **第一遍**：独立写，允许查文档（PyTorch 官方文档、本项目前面的课程），不看答案。
2. **第二遍**：卡住超过 20 分钟，展开答案，**只看思路不复制**，关掉答案自己写出来。
3. **第三遍**：第二天，把这个函数在一个空白文件里从零再写一遍。

第三遍写出来了，才说明你真正掌握了。

## 快速开始

### 方式一：Colab（推荐小白）

1. 打开任意一课，点 ![Colab](https://colab.research.google.com/assets/colab-badge.svg)。
2. 第一次打开时，菜单栏「代码执行程序 → 更改运行时类型」可以选 GPU（第 5 章以后建议用 GPU，前面的 CPU 就够了）。
3. 先运行最上面的 **🔧 环境准备** 单元，它会自动下载本项目的代码。
4. 从上到下依次运行、做练习。想保存自己写的代码：「文件 → 在云端硬盘中保存一份副本」。

### 方式二：本地

```bash
git clone https://github.com/ROI-su7/vla-ladder.git
cd vla-ladder
pip install -e .            # 安装配套代码包 vla_ladder（只依赖 numpy / torch / matplotlib）
pip install jupyterlab
jupyter lab notebooks/      # 打开练习本
```

### 方式三：GitHub Codespaces

在仓库页面点 **Code → Codespaces → Create codespace**，会自动装好环境（CPU 版 PyTorch），在浏览器里就有一个完整的 VS Code。

## 项目目录

```text
vla-ladder/
├── lessons/          # 📖 课程源文件（原理 + 代码 + 练习 + 答案），你主要读这里
├── notebooks/        # 🧪 由 lessons 自动生成的练习本（Colab/Jupyter 打开）
├── vla_ladder/       # 📦 配套代码包
│   ├── envs/         #    课程用到的所有小环境（网格世界、CartPole、二维点、玩具桌面）
│   ├── models/       #    各阶段模型的完整参考实现（GPT、ACT、扩散、流匹配、mini-π0、RLT）
│   └── rl/           #    强化学习算法的完整参考实现
└── tools/            # 构建与测试脚本（tools/run_lessons.py 会把所有课程完整跑一遍）
```

`vla_ladder/` 里的代码是**每个阶段写完之后应该长什么样**。建议在学完一章后，打开对应文件通读一遍，和你自己写的代码比较。
