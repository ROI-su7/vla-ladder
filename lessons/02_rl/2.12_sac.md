## 为什么要学

SAC（Soft Actor-Critic，2018）是**真机强化学习最常用的算法**：

- off-policy + replay buffer：**样本效率高**，真机上每一条数据都很宝贵；
- 自动调节探索强度，超参数鲁棒；
- HIL-SERL（真机精细操作）、RLinf 的真机 RL、**RLT 的 Stage-2 actor-critic**（RLinf 中叫 `fsdp_rlt_ac_policy_worker`，继承自 `fsdp_sac_policy_worker`）都基于 SAC/TD3 框架。

学完本课，第 8 章的 RLT 代码对你来说就只剩"输入换成了 VLA 的特征和参考动作"这一个区别。

## 1. 最大熵目标

普通 RL 最大化期望回报。SAC 在每一步的奖励上**加上策略的熵**：

$$
J(\pi)=\sum_t\mathbb{E}\Big[r(s_t,a_t)+\alpha\,\mathcal{H}\big(\pi(\cdot|s_t)\big)\Big],\qquad\mathcal{H}(\pi(\cdot|s))=\mathbb{E}_{a\sim\pi}[-\log\pi(a|s)]
$$

$\alpha$ 是**温度**，控制"多探索"和"多拿奖励"之间的平衡。好处：

- 鼓励探索，不会过早收敛到一个确定性的次优策略；
- 如果有多种同样好的做法，策略会保留它们（多模态）；
- 对模型误差更鲁棒。

## 2. 软贝尔曼方程

把熵项并入值函数，得到"软"的 Q 函数，它满足

$$
q(s,a)=r+\gamma\,\mathbb{E}_{s'}\Big[\underbrace{\mathbb{E}_{a'\sim\pi}\big[q(s',a')-\alpha\log\pi(a'|s')\big]}_{\text{软状态值 }v(s')}\Big]
$$

和 Sarsa/Expected Sarsa 很像，只是多了 $-\alpha\log\pi$。

## 3. SAC 的三个损失

**(1) critic（twin Q）**：用两个独立的 Q 网络 $q_1,q_2$，目标取**较小者**（clipped double Q，来自 TD3），对抗 Q 值高估：

$$
y=r+\gamma(1-d)\Big(\min_{j=1,2}q_{\bar\phi_j}(s',a')-\alpha\log\pi(a'|s')\Big),\quad a'\sim\pi(\cdot|s')
$$

$$
L_Q=\sum_{j=1,2}\mathbb{E}\big[(q_{\phi_j}(s,a)-y)^2\big]
$$

$\bar\phi$ 是**目标网络**，用 Polyak 平均更新：$\bar\phi\leftarrow\tau\phi+(1-\tau)\bar\phi$，$\tau=0.005$。

**(2) actor**：用**重参数化**采样 $\tilde a=f_\theta(s,\epsilon)$，让动作对 $\theta$ 可导：

$$
L_\pi=\mathbb{E}_{s,\epsilon}\Big[\alpha\log\pi_\theta(\tilde a|s)-\min_j q_{\phi_j}(s,\tilde a)\Big]
$$

即"在保持高熵的同时，让 Q 尽可能大"。对比 DPG：$-q(s,\mu(s))$。

**(3) 自动温度**：设一个目标熵 $\bar{\mathcal H}$（通常取 $-\dim(\mathcal A)$），

$$
L_\alpha=\mathbb{E}_{a\sim\pi}\big[-\alpha\,(\log\pi(a|s)+\bar{\mathcal H})\big]
$$

熵低于目标时 $\alpha$ 增大（多探索），高于目标时 $\alpha$ 减小。

## 4. tanh 压缩与对数概率修正

动作有界（如 $[-2, 2]$），而高斯无界。SAC 先采 $u\sim\mathcal N(\mu,\sigma)$，再 $a=\tanh(u)$。变量替换后对数概率需要修正：

$$
\log\pi(a|s)=\log\mathcal N(u;\mu,\sigma)-\sum_i\log\big(1-\tanh^2(u_i)\big)
$$

（数值稳定写法：$\log(1-\tanh^2 u)=2\big(\log 2-u-\text{softplus}(-2u)\big)$。）

class SquashedGaussianActor(nn.Module):
    def __init__(self, obs_dim, act_dim, act_high, hidden=256):
        super().__init__()
        self.net = nn.Sequential(nn.Linear(obs_dim, hidden), nn.ReLU(), nn.Linear(hidden, hidden), nn.ReLU())
        self.mu = nn.Linear(hidden, act_dim)
        self.log_std = nn.Linear(hidden, act_dim)
        self.act_high = act_high

    def forward(self, obs, deterministic=False):
        """返回 (动作 (B, act_dim)，对数概率 (B,))"""
        h = self.net(obs)
        mu = self.mu(h)
        log_std = self.log_std(h).clamp(LOG_STD_MIN, LOG_STD_MAX)
        std = log_std.exp()
        dist = Normal(mu, std)
        u = mu if deterministic else dist.rsample()
        logp = dist.log_prob(u).sum(-1)
        logp = logp - (2 * (np.log(2) - u - F.softplus(-2 * u))).sum(-1)   # tanh 的雅可比修正
        a = torch.tanh(u) * self.act_high
        return a, logp

```python
def sac_critic_loss(batch, actor, q1, q2, q1_targ, q2_targ, alpha, gamma):
    """batch: obs (B,o), act (B,a), rew (B,), next_obs (B,o), done (B,)；q 网络 q(obs, act) -> (B,)"""
    with torch.no_grad():
        a2, logp2 = actor(batch["next_obs"])
        q_next = torch.min(q1_targ(batch["next_obs"], a2), q2_targ(batch["next_obs"], a2))
        y = batch["rew"] + gamma * (1 - batch["done"]) * (q_next - alpha * logp2)
    return F.mse_loss(q1(batch["obs"], batch["act"]), y) + F.mse_loss(q2(batch["obs"], batch["act"]), y)


def sac_actor_alpha_loss(batch, actor, q1, q2, log_alpha, target_entropy):
    """返回 (actor_loss, alpha_loss, 信息字典)"""
    alpha = log_alpha.exp().detach()
    a_new, logp_new = actor(batch["obs"])
    q_new = torch.min(q1(batch["obs"], a_new), q2(batch["obs"], a_new))
    actor_loss = (alpha * logp_new - q_new).mean()
    alpha_loss = -(log_alpha * (logp_new.detach() + target_entropy)).mean()
    return actor_loss, alpha_loss, {"alpha": alpha.item(), "entropy": -logp_new.mean().item()}
```

class QNet(nn.Module):

        super().__init__()

    def forward(self, obs, act):
        return self.net(torch.cat([obs, act], -1)).squeeze(-1)

### 训练 SAC（CPU 上约 2–4 分钟）

```python
class Buffer:
    def __init__(self, cap, obs_dim, act_dim):
        self.o = np.zeros((cap, obs_dim), np.float32); self.a = np.zeros((cap, act_dim), np.float32)
        self.r = np.zeros(cap, np.float32); self.o2 = np.zeros((cap, obs_dim), np.float32); self.d = np.zeros(cap, np.float32)
        self.cap, self.ptr, self.size = cap, 0, 0

    def add(self, o, a, r, o2, d):
        self.o[self.ptr], self.a[self.ptr], self.r[self.ptr], self.o2[self.ptr], self.d[self.ptr] = o, a, r, o2, d
        self.ptr = (self.ptr + 1) % self.cap; self.size = min(self.size + 1, self.cap)

    def sample(self, n):
        i = np.random.randint(0, self.size, n)
        return {"obs": torch.as_tensor(self.o[i]), "act": torch.as_tensor(self.a[i]), "rew": torch.as_tensor(self.r[i]),
                "next_obs": torch.as_tensor(self.o2[i]), "done": torch.as_tensor(self.d[i])}


def polyak(target, source, tau):
    with torch.no_grad():
        for pt, p in zip(target.parameters(), source.parameters()):
            pt.mul_(1 - tau).add_(p, alpha=tau)


def train_sac(total_steps=12_000, start_steps=1000, batch_size=256, gamma=0.99, tau=0.005, lr=3e-4, seed=0):
    set_seed(seed)
    env = Pendulum(); od, ad, high = 3, 1, 2.0
    actor = SquashedGaussianActor(od, ad, high)
    q1, q2 = QNet(od, ad), QNet(od, ad)
    q1t, q2t = QNet(od, ad), QNet(od, ad); q1t.load_state_dict(q1.state_dict()); q2t.load_state_dict(q2.state_dict())
    log_alpha = torch.zeros(1, requires_grad=True)
    opt_pi = torch.optim.Adam(actor.parameters(), lr=lr)
    opt_q = torch.optim.Adam(list(q1.parameters()) + list(q2.parameters()), lr=lr)
    opt_a = torch.optim.Adam([log_alpha], lr=lr)
    buf = Buffer(100_000, od, ad)
    obs, _ = env.reset(seed=seed); ep_ret, rets, ends, alphas = 0.0, [], [], []
    for step in range(total_steps):
        if step < start_steps:                       # 一开始纯随机探索，填充 buffer
            act = np.random.uniform(-high, high, size=ad).astype(np.float32)
        else:
            with torch.no_grad():
                act = actor(torch.as_tensor(obs)[None])[0][0].numpy()
        obs2, r, term, trunc, _ = env.step(act)
        buf.add(obs, act, r, obs2, float(term))      # Pendulum 没有 terminated，只有 truncated
        obs, ep_ret = obs2, ep_ret + r
        if term or trunc:
            rets.append(ep_ret); ends.append(step); obs, _ = env.reset(); ep_ret = 0.0
        if step >= start_steps:
            batch = buf.sample(batch_size)
            ql = sac_critic_loss(batch, actor, q1, q2, q1t, q2t, log_alpha.exp().item(), gamma)
            opt_q.zero_grad(); ql.backward(); opt_q.step()                     # 1) 先更新 critic
            al, alp, info = sac_actor_alpha_loss(batch, actor, q1, q2, log_alpha, -float(ad))
            opt_pi.zero_grad(); al.backward(); opt_pi.step()                   # 2) 再更新 actor（用更新后的 Q）
            opt_a.zero_grad(); alp.backward(); opt_a.step()                    # 3) 最后更新温度
            polyak(q1t, q1, tau); polyak(q2t, q2, tau)
            alphas.append(info["alpha"])
    return actor, rets, ends, alphas

actor, rets, ends, alphas = train_sac()
fig, ax = plt.subplots(1, 2, figsize=(10, 3.5))
ax[0].plot(ends, rets, "o-", ms=3); ax[0].set_xlabel("env step"); ax[0].set_ylabel("episode return"); ax[0].set_title("SAC on Pendulum")
ax[1].plot(alphas); ax[1].set_title("temperature alpha (auto-tuned)"); ax[1].set_xlabel("update")
plt.tight_layout(); plt.show()
print("最后 5 局平均回报:", np.mean(rets[-5:]))
assert np.mean(rets[-5:]) > -400
```

> 对比 2.11：PPO 用了约 20 万步，SAC 只用 1.2 万步就达到相近水平。这就是 off-policy + replay buffer 的威力，也是真机 RL 首选 SAC 类方法的原因。

## 5. 从 SAC 到 RLT：只差几处改动

打开 RLinf 的 `rlinf/models/embodiment/mlp_policy/rlt_mlp_policy.py`，你会看到 RLT Stage-2 的 actor-critic 与本课的 SAC 几乎一一对应：

| | 本课 SAC | RLT（RLinf 实现） |
|---|---|---|
| actor 输入 | 观测 $s$ | **RL token** $z_{rl}$ + 本体状态 + **VLA 的参考动作块** $a_{ref}$ |
| actor 输出 | 一个动作 | 一个**动作块**（可选"残差"：$a=a_{ref}+\Delta$，Δ 头零初始化） |
| 标准差 | 网络输出 + 自动温度 | **固定的小标准差**（如 0.002 rad），只在参考动作附近小范围探索 |
| critic | twin Q$(s,a)$ | twin Q$(z_{rl},\text{proprio},a_{chunk})$ |
| actor 损失 | $\alpha\log\pi-\min Q$ | $-\min Q+\beta\|a-a_{ref}\|^2$（**BC 正则**：不要离 VLA 太远） |
| 参考动作 dropout | 无 | 训练时随机把 $a_{ref}$ 置零，防止 actor 只会抄参考动作 |
| 数据 | 自己探索 | 自己探索 + **人类干预/接管**的数据 |

这些改动的共同目的：**在 VLA 已经"大致会做"的基础上，只学习最后一点精度**。所以不需要大范围探索，也不能离 VLA 太远。第 8 章会从零实现它。

## 小结

- 最大熵目标：回报 + α·熵，鼓励探索。
- 三个损失：twin Q 的软 TD 目标（取 min 防高估）、重参数化的 actor 损失、自动温度。
- tanh 压缩需要对数概率修正。
- off-policy + replay buffer = 高样本效率 → 真机首选。
