# 第 3 章 · L1 模仿学习：行为克隆及其两大难题

> 阶梯 L1：**一个 MLP 行为克隆策略**，在二维点环境中跑通"采数据 → 训练 → 评估"的完整闭环。

VLA 的训练方式本质上就是**行为克隆（Behavior Cloning, BC）**：给它看人类遥操作的示教，让它模仿。π0 的预训练和微调、ACT、Diffusion Policy 都是 BC，只是网络更大、动作分布的建模方式更强。

所以先用最简单的 BC 把核心问题摸透：

| 课 | 内容 | 揭示的问题 |
|---|---|---|
| [3.01 行为克隆与 DAgger](3.01_behavior_cloning.md) | 数据集、归一化、BC 训练与评估、复合误差、DAgger | **分布偏移**：策略犯小错 → 进入没见过的状态 → 犯更大的错 |
| [3.02 多模态与动作分块](3.02_multimodality.md) | 双峰示教、MSE 的"平均"灾难、混合密度网络、动作分块 | **多模态**：同一个状态有多种正确做法，MSE 会取平均 |

这两个问题，正是后面所有方法要解决的：

- 动作分块（ACT）、扩散/流匹配（Diffusion Policy、π0）→ 解决多模态；
- DAgger、人类干预（HIL-SERL、RLT 的接管数据）、RL → 解决分布偏移。

> 本章使用 `vla_ladder.envs.point_env` 中的两个二维点环境。所有实验在 CPU 上几十秒内完成。
