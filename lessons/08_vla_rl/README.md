# 第 8 章 · L6 VLA + RL：让 VLA 超越示教

> 阶梯 L6：**在自己写的 mini-π0 上，从零实现 RLT（RL Token）和 RECAP（优势条件化）**，并给出真机落地清单。

到第 7 章为止，VLA 的能力上限是示教数据：示教者插得不够深、动作慢、偶尔犯错，模型都会照单全收。强化学习让模型能**根据结果（奖励）而不只是模仿**来改进。

| 课 | 内容 | 对应你的真实工作 |
|---|---|---|
| [8.01 VLA + RL 全景](8.01_vla_rl_overview.md) | 为什么要 RL、主流方法对比（PPO/流 SDE、残差 RL、DSRL、RLT、RECAP、HIL-SERL） | 选型 |
| [8.02 从零实现 RLT](8.02_rlt.md) | RL token（重建预训练）+ 残差 actor-critic（参考动作、固定 σ、BC 正则） | RLinf 的 RLT Stage 1 / Stage 2 |
| [8.03 从零实现 RECAP](8.03_recap.md) | 价值函数、优势、优势条件化训练、无分类器引导 | π\*0.6 的 RECAP |
| [8.04 真机落地清单](8.04_real_world.md) | 评测协议、置信区间、奖励与干预、线头对插的分阶段方案 | ALOHA / Piper 线头对插 |

本章使用的玩具任务：桌面找方块，但**示教者有系统性偏差**（总是停在离方块中心 5cm 的地方，就像插线总是插不到底），或者**示教质量参差不齐**（有些示教先走错再改正）。RL 的任务就是**超越这些不完美的示教**。

> 本章需要 GPU。每课的实验在 GPU 上约 5~8 分钟。
